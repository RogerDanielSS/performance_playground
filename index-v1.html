❌ Bad Practices Avoid
Layout: float + fixed px
Uses float: left with clearfix hacks. Fixed pixel widths — not responsive. Forces reflows when resizing.

⚠️ Reflow trigger: float + fixed widths cause layout recalculations on resize.
Animation: left / top
Animating left triggers reflow on every frame. Uses setInterval — not synced with screen refresh.

⚠️ Cost: triggers Layout → Paint → Composite on every frame. ~30-40 FPS.
Hover: width + height
Changing width and height on hover triggers reflow. Causes layout shift for surrounding elements.
HOVER
⚠️ Cost: reflows the entire subtree. Surrounding elements shift.
Toggle: display: none
Using display: none removes the element from layout — triggers reflow and shifts other elements.
VISIBLE
⚠️ Cost: full reflow. Surrounding elements move.
Image: no lazy, no sizing
No width/height attributes → CLS. No lazy loading → blocks rendering. Large file.
⚠️ CLS: layout shifts as image loads. No lazy loading.
Selectors: deeply nested
Overly specific, nested selectors. Hard to maintain. Uses !important.
.header .nav .nav-list .nav-item .nav-link .icon { ... }
!important used everywhere.
⚠️ Cost: slower style recalculations. Hard to override.
✅ Good Practices Adopt
Layout: flexbox + gap
Uses display: flex with flex-wrap and gap. Responsive — items wrap naturally. No clearfix hacks.

Using transform: scale() on hover triggers composite only. No layout shift. Smooth 60fps.

Using visibility: hidden preserves layout — no reflow. Element is invisible but space is maintained.

Image: lazy + responsive + sized
width/height attributes prevent CLS. loading="lazy" defers off-screen images. srcset serves responsive sizes.
✅ CLS: 0.00. Image loads without shifting layout.
Selectors: flat + BEM
Flat, specific selectors. Uses BEM methodology. CSS custom properties (variables) for theming. No !important.

.card__title--large { font-size: 1.2rem; }

✅ Optimized: fast style calculations. Maintainable, scalable.
